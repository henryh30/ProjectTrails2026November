<h1>Project spår</h1>

<h2>About</h2>

This project is a landingpage created for the brand "Spår" and the project was about defining the brand and create it from the beginning with a start theme such as the page being modernised.

<h2>Tools</h2>

Github and Visual Studio Code has been used to save the project and changes made in Visual Studio Code. Programming languages used have been PHP, HTML, Css and Javascript. Php was used to make the HTML code less repetitive whereas Css was used to rearrange the structure of the elements on the page. Javascript was used to add functions to the page such as changing the image source depending on which color button is pressed (the circular color buttons on a big section where you design the product).

<h2>Method</h2>

This project started with a meetup with the project members and brainstorming occured to pick out the idea which mostly describes our interpretation of the brand's background and what they stand for. Designers have prototyped a graybox in Figma after consulting me as the developer and graybox have been adjusted to fit my knowledge. Meanwhile the page was being developed to look similar to the design from the Digital Design class, the Computer Graphics have been consulted by the Design team as well to make sure they 3D model the right products. During my time of developing the page, I have been experimenting and received support from the Design team in my Project when functions or idea became vague and I had no clear picture of how the code would look like.
